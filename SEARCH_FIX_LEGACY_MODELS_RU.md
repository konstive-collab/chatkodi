# Фикс поиска после UI-shell

Что было:
- новая версия GUI искала локальные модели в `.chatkodi/models_cache/`
- в старых рабочих сборках модели уже лежали в `models_cache/` в корне проекта
- из-за этого healthcheck видел, что моделей «нет», включался safe-mode `all_models_missing`, и поиск не инициализировался

Что исправлено:
- добавлена обратная совместимость по путям к моделям
- поиск embedding-модели и LLM теперь смотрит:
  1. в `.chatkodi/models_cache/`
  2. в legacy `models_cache/` в корне проекта
- если найден старый рабочий кэш, он используется автоматически
- новая схема хранения не сломана: если legacy-кэша нет, проект продолжает использовать `.chatkodi/models_cache/`

Что проверить после замены:
1. `python healthcheck.py`
2. в блоке models должно появиться `embeddings: true`
3. safe-mode `all_models_missing` больше не должен включаться при наличии старых моделей
4. поиск по документам должен снова инициализироваться
