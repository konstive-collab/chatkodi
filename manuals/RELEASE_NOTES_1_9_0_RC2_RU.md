# ChatKodi 1.9.0-rc2

Исправляющий релиз по результатам технического аудита 1.9.0-rc1.

## Основные исправления

- исправлен фильтр нерелевантных чанков при совпадениях сущностей;
- реализован настоящий token-streaming и безопасная остановка генерации;
- неизменившийся FAISS-индекс повторно используется с проверкой точных ID чанков и fingerprint embedding-модели;
- частичные модели и папки только с метаданными больше не считаются готовыми, добавлен локальный SHA-256-манифест;
- объединены детерминированная классификация интентов и разбор JSON-ответов LLM;
- удалены недостижимые копии поискового, чат- и GUI-кода;
- инспектор использует уже выполненный поиск и публичный API ChatManager;
- добавлены история/экспорт диалога и drag-and-drop документов без перезаписи файлов;
- добавлена базовая поддержка английских вопросов;
- добавлено базовое извлечение действий, способов и мест из английского текста;
- предметный словарь акторов вынесен в конфигурацию;
- добавлен опциональный offline cross-encoder reranker;
- подключён расширенный набор проверки точности поиска;
- зависимости закреплены версиями, добавлены `pyproject.toml` и Windows CI.
- удалены оставшиеся абсолютные/родительские пути разработчика из конфигурации генерации.

## Совместимость

Обучаемый reranker по умолчанию выключен. При его отсутствии продолжает работать
прежний эвристический rerank. Стабильный выпуск 1.8 не изменялся.
