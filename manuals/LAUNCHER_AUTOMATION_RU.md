# Автоматическая подготовка окружения

Кнопка **Подготовить автоматически** запускает цепочку команд, которая подготавливает ChatKodi под текущий компьютер.

## Что происходит внутри

1. Создаётся виртуальное окружение `.venv`, если его ещё нет.
2. Ставятся зависимости из `requirements.txt`.
3. Лаунчер проверяет NVIDIA/CUDA.
4. Запускается `download_models.py` для проверки и скачивания моделей.
5. Запускается `tools.doctor`, который проверяет Python, проект, документы, модели и профиль железа.

## Почему это лучше ручного запуска

Лаунчер очищает старые переменные окружения перед стартом. Это важно: если раньше был выбран режим без LLM, старое значение `CHATKODI_DISABLE_LLM=1` больше не должно случайно ломать запуск в режиме Авто.

## Когда нужна ручная установка

Ручная вкладка нужна только если автоматическая подготовка не прошла. Например:

- нет интернета;
- pip не может скачать пакет;
- модель скачалась частично;
- Windows блокирует выполнение PowerShell-скриптов.

## Быстрый ремонт

Если программа странно запускается после экспериментов:

1. Откройте лаунчер.
2. Нажмите **Вернуть всё в Авто**.
3. Нажмите **Подготовить автоматически**.
4. Нажмите **Запустить ChatKodi**.

Если проблема осталась, создайте **Support bundle** и смотрите `logs/chatkodi.log`.
