# ChatKodi 1.7.16-hotfix.2

## Главное изменение

Источники ответа в чате теперь показываются как аккуратный выпадающий список в зеленом стиле ChatKodi, а не как набор отдельных синих кнопок.

## Что исправлено и улучшено

- Добавлен свернутый блок `Источники ответа • N` под ответами ассистента.
- По клику блок раскрывает список документов и кнопку `Открыть` для каждого источника.
- Оформление перенесено в `gui/styles.py`, чтобы элемент поддерживал темную и светлую темы.
- Улучшен парсер источников: теперь он видит не только строки `source.docx: цитата`, но и списки документов без двоеточия.
- Список источников дедуплицируется по физическому пути файла.
- Для streaming-ответов список источников добавляется после завершения генерации.
- Документы по-прежнему открываются через системное приложение Windows/Linux/macOS.
