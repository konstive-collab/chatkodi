# ChatKodi 1.7.19-rc1 — уточнения по данным ответа

## Главное

Добавлена кнопка **«Спросить по данным»** под ответами ChatKodi. Она позволяет задать уточняющий вопрос именно по уже показанному ответу, без нового запуска RAG-поиска по корпусу.

## Изменения

- Под каждым неслужебным ответом ассистента появился компактный зелёный блок **«Спросить по данным»**.
- Блок раскрывается плавно и показывает поле ввода для уточняющего вопроса.
- Уточняющий вопрос отправляется в новый метод `ChatManager.answer_from_context()`.
- Метод использует текст выбранного ответа как временный контекст и не запускает новый поиск по документам.
- Если локальная LLM недоступна, ChatKodi честно сообщает, что ответить по данным сообщения не может, и не подменяет это новым поиском.
- Добавлены стили для тёмной и светлой темы.
- Добавлена документация `docs/CONTEXT_ASK_RU.md`.

## Зачем это сделано

Раньше для любого уточнения пользователь был вынужден снова отправлять обычный вопрос. Система заново запускала поиск и могла потерять связь с предыдущим ответом. Новый режим решает именно этот сценарий: «я вижу найденные данные, хочу спросить по ним».
