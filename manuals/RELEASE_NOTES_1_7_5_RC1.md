# ChatKodi 1.7.5-rc1 — Precision & Performance Core

Эта сборка усиливает ветку 1.7 в сторону точности, предсказуемости и устойчивости на больших корпусах.

## Главное

- Добавлен адаптивный `EvidenceBudget`: разные лимиты для точных, диапазонных, статистических и сводочных запросов.
- Добавлен `diversify_chunks`: диапазонные и статистические вопросы больше не должны схлопываться в один сильный фрагмент одного документа.
- Добавлен `AnswerQuality Guard`: LLM-ответ проверяется перед показом пользователю. Если модель уходит в ложное «нет информации», отказ или слишком слабый ответ, а structured-слой нашёл доказательства, система отдаёт structured-answer.
- Для среднеуверенного LLM-ответа может добавляться блок «Структурная проверка», чтобы пользователь видел алгоритмическую опору ответа.
- `MemoryGuard` теперь дополнительно ограничивается evidence-budget, поэтому RAG не пытается раздувать prompt там, где нужен алгоритмический ответ.
- В trace/support диагностике появились сведения о budget: причина, лимиты, заметки.

## Улучшения поведения

### Точные вопросы

Фактологические вопросы получают узкий бюджет: меньше документов, меньше чанков, больше приоритета доказательству.

### Диапазоны

Диапазоны получают широкий evidence-budget и diversity selection, чтобы собирать несколько дней/документов, а не один top-1 chunk.

### Статистика

Статистические вопросы получают больше evidence records и structured-first priority. LLM не должна заменять подсчёты свободным текстом.

### Большие корпуса

На больших корпусах context cap становится жёстче, а structured-first включается раньше.

## Проверка

Проверено синтаксически через direct compile всех `.py` файлов без записи pycache.

Рекомендуемый следующий тест:

```powershell
python tools/benchmark_runner.py benchmark_cases.sample.json
```

И затем golden dataset заказчика: 20–50 реальных вопросов с ожидаемым документом, фрагментом и типом ответа.
