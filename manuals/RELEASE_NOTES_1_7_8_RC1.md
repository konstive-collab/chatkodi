# ChatKodi 1.7.8-rc1 — Scoped Statistics / Range UX Fix

Эта сборка чинит перекос, при котором диапазонные вопросы вроде
`На каких направлениях работал ... с 10 по 12 июня 2025 года?` могли уходить
в широкий статистический summary и показывать лишние документы, повторяющиеся
паттерны и неочевидные счётчики.

## Что изменено

- Вопросы `на каких направлениях`, `какие направления`, `каких направлениях`
  теперь классифицируются как `location`, а не как широкий `range_summary`.
- Для location/method-запросов с диапазоном включён компактный range-scope budget:
  период учитывается, но ответ не превращается в широкую аналитику по всему корпусу.
- Evidence/statistics теперь жёстче ограничиваются найденными документами и периодом.
- Для документов вида `10.docx`, `11.docx`, `12.docx` дата может быть восстановлена
  из имени файла в рамках месяца/года, указанных в вопросе.
- EventStore больше не тащит события без восстановимой даты в диапазонную статистику.
- `рБпЛА №11` и похожие единицы больше не попадают в `top_methods` как “способ”.
- Формат статистики стал понятнее: счётчики теперь выводятся как `— N упомин.`, а не
  как непонятные скобки.

## Ожидаемый эффект

Для вопроса про направления за период ответ должен быть ближе к формату:

> По найденным данным для рбпЛА №11 указано направление/место: Изюмское. Период: 2025-06-10 — 2025-06-12.

А подробная статистика должна включаться только для настоящих статистических вопросов:
`где чаще`, `как часто`, `с какой периодичностью`, `сколько раз`, `по каким дням`.
