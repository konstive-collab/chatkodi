# Результат исправлений по аудиту ChatKodi 1.9.0-rc1

Статус: исправляющий кандидат `1.9.0-rc2`.

## Исправлено

- фильтр сущностей больше не пропускает нерелевантные чанки;
- token-streaming выполняется во время генерации, добавлена кооперативная отмена;
- FAISS переиспользуется только при совпадении ID чанков, размерности и fingerprint embedding-модели;
- менеджер моделей отклоняет частичные веса и папки только с метаданными;
- для полностью скачанных моделей создаётся и проверяется локальный SHA-256-манифест;
- история диалога сохраняется локально, экспортируется в TXT/JSON и очищается из GUI;
- добавлены drag-and-drop документов и защита от перезаписи одноимённых файлов;
- классификация интентов, определение якорей и разбор JSON сведены к общим реализациям;
- предметный словарь акторов вынесен в конфигурацию;
- добавлены английские вопросные интенты и базовое извлечение фактов из английского текста;
- инспектор получает результат уже выполненного поиска через публичный API;
- удалены недостижимые копии chat/search/LLM/GUI и старые копии model-manager;
- конфиги, документация и runtime-дефолты синхронизированы; удалён путь разработчика;
- зависимости закреплены версиями, добавлены `pyproject.toml` и Windows CI;
- расширенный accuracy-набор подключён к benchmark CLI;
- добавлен опциональный локальный cross-encoder reranker.

## Подтверждённые проверки

- `compileall` для `core`, `gui`, `tools`, `integrations`, `tests` и `main.py`;
- 73 автоматических теста;
- запуск GUI: окно `ChatKodi 1.9.0-rc2` открылось и отвечало Windows;
- отдельный чистый пакет прошёл те же 73 теста;
- архив не содержит моделей, документов пользователя, логов, runtime-кэша и бинарных payload-файлов.

## Что требует отдельного решения владельца

- тип лицензии проекта (`LICENSE`) нельзя выбирать автоматически;
- подпись Windows-бинарников требует сертификата владельца;
- локальный SHA-256 фиксирует состояние после загрузки, но не заменяет опубликованный владельцем модели эталонный хэш;
- обучаемая модель reranker не включена в исходники и по умолчанию выключена;
- полный распил крупных `ChatManager`/`HybridSearch` на новые сервисы и полноценная мультиязычность — отдельные архитектурные этапы, а не безопасный hotfix.
