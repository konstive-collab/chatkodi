# Автоматический режим LLM

В обычном сценарии пользователь не выбирает модель вручную. В лаунчере стоит режим «Авто», а ChatKodi сам использует скачанную локальную модель или прежний автоматический алгоритм поиска модели.

## Что делает «Авто»

- Не передаёт ручной путь модели, если пользователь его не выбирал.
- Не отключает LLM, если не выбран режим «Только поиск».
- При запуске через лаунчер очищает старые переменные окружения, которые могли случайно отключить модель.
- Оставляет возможность ручного выбора модели во вкладке «Модели».

## Когда выбирать вручную

Ручной выбор полезен, если в `models_cache` лежит несколько LLM и нужно проверить конкретную модель. Для обычного запуска лучше оставить «Авто».

## Если написано «LLM не загружена»

1. Откройте лаунчер.
2. Проверьте вкладку «Модели».
3. Убедитесь, что выбрано «Авто» или конкретная установленная модель, а не «Только поиск».
4. Нажмите «Подготовить автоматически».
5. Запустите ChatKodi из лаунчера.
