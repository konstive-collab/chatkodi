# ChatKodi 1.8.0-rc2

## Главное

Версия rc2 — визуальная и продуктовая полировка 1.8. Интерфейс стал спокойнее, а лаунчер получил авто-подготовку и нормальную модель «авто сначала, ручные настройки потом».

## Интерфейс

- Ручные настройки поиска перенесены в раскрывающийся блок «Доп. настройки».
- Верхняя панель чата теперь показывает короткий авто-статус вместо набора постоянных комбобоксов.
- Обновлена тёмная и светлая тема: меньше кислотного зелёного, больше нейтральных поверхностей.
- Обновлён приветственный текст и подсказки.

## Лаунчер

- Добавлен основной сценарий «Подготовить автоматически».
- Лаунчер сам выбирает CPU/CUDA PyTorch по профилю и наличию NVIDIA.
- Добавлен список установленных LLM с режимом «Авто» по умолчанию.
- Ручные профили запуска перенесены в отдельную вкладку.
- При ручном выборе модели передаётся `CHATKODI_MODEL_PATH`.
- Режим без LLM передаёт `CHATKODI_DISABLE_LLM=1`.

## Ядро

- `load_llm_model()` теперь уважает `CHATKODI_MODEL_PATH` и `CHATKODI_DISABLE_LLM`.
- Прежний автоматический поиск модели сохраняется, если ручной путь не задан.
