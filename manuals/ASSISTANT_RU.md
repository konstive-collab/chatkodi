# Ассистент ChatKodi

Один чат для вопросов, файлов и поручений — без режимов и переключателей:
ChatKodi сам понимает, что нужно сделать, выполняет и показывает результат. Всё работает на этом
компьютере, без интернета: файлы, фото и голос никуда не передаются.

## Что можно делать

| Что вы делаете | Что делает ChatKodi |
|---|---|
| Задаёте вопрос по документам | Ищет в библиотеке и отвечает с цитатой и источником (как раньше) |
| Присылаете фото или скан без слов | Говорит, что это за документ, распознаёт текст и таблицы, сохраняет в Word/Excel, показывает связанные документы библиотеки |
| «Проверь по нашим нормативам» | Находит требования в библиотеке и сверяет с ними данные файла: таблица «показатель — значение — требование — итог» с дословными основаниями |
| «Оформи заключение по нашему образцу» | Находит образец в библиотеке и составляет новый документ той же формы по данным файла, выдаёт DOCX в оформлении образца |
| «Сделай таблицу Excel» | Переводит фото/скан в XLSX с настоящими числами |
| «Сделай презентацию по этому отчёту» | Раскладывает данные по слайдам и выдаёт PPTX; «по образцу нашей презентации» или с приложенной презентацией — в её оформлении и с тем же порядком слайдов (содержимое образца не переносится) |
| «Напиши методичку / инструкцию / положение / программу обучения по …» | Составляет план разделов (по образцу того же вида из библиотеки, если он есть) и пишет каждый раздел отдельно по материалам библиотеки; выдаёт DOCX |
| «Составь план-конспект урока на 40 минут» | Таблица «содержание — время — указания» по частям занятия; минуты по частям и итог считает программа и подгоняет под длительность |
| «Составь расписание для 7А и 7Б…», «График дежурств с … по …» | Условия выписывает модель, раскладывает программа: без накладок по группам и преподавателям, дежурства поровну; выдаёт XLSX (лист на группу) |
| «Выставь оценки по шкале», «Проверь ведомость» | Шкалу читает модель, оценки считает программа; пустые заполняет, неверные исправляет, Excel с формулами |
| «Что изменилось во второй редакции?» | Сравнивает два документа построчно и описывает все изменения |
| «Переведи на английский» | Переводит файл или предыдущий ответ, длинный перевод — сразу файлом |
| «Кратко перескажи» | Главное из файла: факты, числа, сроки, кто что должен |
| «Напиши ответ на это письмо: …» | Пишет готовый текст, обязательно с вашими датами и решениями |
| «Покажи, сколько места на диске C» | Составляет команду PowerShell; команды, которые только читают, выполняет сразу, остальные — по настройке самостоятельности |
| «Проверь протокол и оформи заключение» | Несколько задач — составляет план и выполняет шаги по очереди |
| «Найди акт приёмки», «Приложи договор к чату» | Ищет файлы в библиотеке, на Рабочем столе, в Документах, Загрузках и ваших папках |
| «Переименуй…», «Перенеси в папку Архив» | Переименовывает и переносит без перезаписи, с кнопкой «Отменить» |
| «Отправь это письмом через Outlook» | Пишет письмо и открывает черновик с вложениями — отправляете вы |
| «Открой калькулятор», «Открой в Excel» | Запускает программу или открывает файл |

## Как приложить файл

- кнопка **📎** слева от поля ввода или **Файл → Приложить файлы к чату** (Ctrl+O);
- перетащите файлы мышью в окно чата (на странице «Документы» перетаскивание добавляет файлы в библиотеку);
- скопируйте картинку или файл и нажмите **Ctrl+V** в поле ввода.

Поддерживаются фото и сканы (JPG, PNG, BMP, TIFF, WEBP), PDF (в том числе сканы без текстового слоя),
Word, Excel, PowerPoint, RTF, ODT, TXT, HTML, письма EML, аудиозаписи WAV (MP3/OGG/FLAC — если их читает сборка whisper).
Файл можно отправить без текста — ассистент сам предложит, что с ним сделать.

## Файлы в ответах

Созданный документ показывается листом бумаги: **левый клик** — скачать, **правый клик** — развернуть по листам
прямо в чате, там же **«Править текст»** перед скачиванием. Под листом: **Открыть в Word**, **В папке**,
**В библиотеку** (файл добавляется в библиотеку и индексируется — по нему можно будет искать).
Все созданные файлы лежат в `runtime\outputs\<дата>` (**Файл → Открыть папку созданных файлов**).

## Проверки, которые делает программа (а не модель)

- **Таблицы на фото**: количество × цена = сумма, «Итого» = сумма столбца, «Среднее» = среднее столбца.
  Если цифра распознана неверно, арифметика не сходится — вы увидите ⚠ с номером строки.
- **Проверка по нормативам**: каждое требование подтверждается дословной цитатой из документа библиотеки;
  числа сравниваются программой («не менее 32,7», «от 17 до 23») — если модель ошиблась, вывод исправляется.
- **Новые документы, письма, сравнения**: каждое число и дата сверяются с исходными данными. Значения,
  которых нет в данных (например, перенесённые из образца), отмечаются ⚠ — проверьте их.
- **Вопросы «можно ли…», «укладывается ли…»**: значение и условие («34 000 руб.» и «не более 30 000 руб.»)
  сравнивает программа; под ответом строка «Проверено программой».
- **«Сколько было …»**: модель перечисляет объекты дословными строками, считает их программа.
- **Расписания, графики, время в плане занятия** раскладывает и считает программа, а не модель.

## Голос

- **🎤** — скажите запрос; запись остановится сама после паузы, текст уйдёт ассистенту.
- **🔇/🔊** — озвучивать ответы (после голосового запроса включается само).
- **Файл → Голосовой диалог** — после ответа микрофон снова слушает: разговор без клавиатуры.

Распознавание — whisper large-v3-turbo на видеокарте (доли секунды на фразу), голос — Piper.
Буквенно-цифровые обозначения (например, «АБ-10») распознаются так, как они записаны в ваших документах.

## Личные инструкции

**Файл → Личные инструкции…** — правила для всех ответов: кто вы и ваша организация (для подписи писем),
стиль, обязательные реквизиты, формат дат, язык. Без инструкций ассистент ставит в письмах поля
[должность] [ФИО], а не придумывает подписанта.

## Самостоятельность и подтверждения

Каждое действие программа относит к классу риска по самим командам (не только по мнению модели):
**только чтение** → **изменение** → **опасно** → **необратимо**. Что выполняется без вопроса, задаётся в
**Настройки → Самостоятельность**:

| Настройка | Без вопроса | Спрашивает |
|---|---|---|
| Только с разрешения (по умолчанию) | чтение и поиск | всё остальное |
| Автомат | чтение, обычные изменения (открыть, скопировать, переименовать с отменой) | опасное и необратимое |
| Полная самостоятельность | всё, кроме необратимого | необратимое |

Необратимое — удаление мимо Корзины, форматирование, работа с дисками — подтверждается **всегда**.

## Команды на компьютере

Ассистент составляет команды PowerShell и объясняет, что они сделают. Перед показом PowerShell
проверяет синтаксис и что все командлеты существуют (сама команда при этом не запускается); если проверка
не прошла, ассистент переписывает команду. Когда нужно подтверждение — кнопка **▶ Выполнить**; для команд,
которые могут удалить или изменить данные и настройки, — повторное подтверждение с предупреждением.
Вывод команды показывается в чате с объяснением.

## Память между чатами

Ассистент запоминает устойчивые факты из ваших сообщений — кто вы, организация, постоянные адресаты,
всё, что вы просите «запомнить», — и учитывает их во всех чатах. **Настройки → Память…** показывает список:
лишнее можно удалить, нужное — добавить, всё — очистить. Память можно выключить там же.

## Если что-то не так

- «Распознавание изображений недоступно» — нет файла зрения модели `mmproj-*.gguf` рядом с LLM в `models_cache\llms`.
- «Голосовой ввод недоступен» — нет папки `models_cache\speech` (whisper, модель, Piper, голоса).
- Файл не находится — добавьте его папку в **Настройки → Папки для поиска…**.
