# Следующие итерации ChatKodi

## Итерация 1.7.17 — источники ответа

Цель: сделать проверку ответа удобной и естественной.

Готово:

- выпадающий блок `Источники ответа`;
- кнопка `Показать` для открытия документа внутри ChatKodi;
- кнопка `Открыть` для запуска файла во внешней программе;
- попытка найти и выделить цитату во внутреннем предпросмотре;
- единая зелёная стилистика кнопок.

## Итерация 1.7.18 — точные evidence-координаты

Цель: перейти от поиска цитаты по тексту к стабильным координатам доказательства.

План:

- добавить в evidence поля `chunk_id`, `start_char`, `end_char`;
- для DOCX по возможности хранить `paragraph_index`;
- для PDF хранить `page`;
- передавать эти поля из структурного ответа в GUI;
- сделать переход `Показать` не приблизительным, а точным.

## Итерация 1.7.19 — диагностика статистики

Цель: перестать угадывать, почему статистика посчитала лишнее.

План:

- сохранять JSON-разбор ответа рядом с логами;
- показывать в диагностике выбранную единицу счёта: упоминания, факты, эпизоды, документы, шаги;
- показывать отброшенные кандидаты и причину отбраковки;
- добавить регрессионные тесты на `рБпЛА №11`, `склад БК`, `Изделие-51` и нейтральные документы вроде рецептов.

## Итерация 1.7.20 — полировка UX

Цель: сделать интерфейс спокойнее и быстрее для ежедневной работы.

План:

- компактные карточки доказательств;
- подсветка найденных фрагментов внутри документа;
- быстрый фильтр по документам;
- отдельный режим «проверить ответ по источникам»;
- улучшение сообщений об ошибках без технического шума.
