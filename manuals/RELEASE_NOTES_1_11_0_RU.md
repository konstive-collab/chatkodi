# ChatKodi 1.11.0 — ассистент: файлы, фото, документы по образцу, голос

1.11.0 превращает ChatKodi из «вопрос — ответ по папке» в локального рабочего ассистента. В чат можно
бросить документ, фото или скан — ChatKodi сам поймёт, что это, сверится с библиотекой и выполнит задачу:
распознает, проверит по нормативам, оформит документ по образцу, переведёт, сравнит редакции, ответит
голосом. Всё по-прежнему работает на одном компьютере без интернета. Подробно — `manuals/ASSISTANT_RU.md`.

## Новое

- **Режим «Ассистент»** (по умолчанию): один чат для вопросов, файлов и поручений. Модель выбирает
  действие по строгой схеме, программа его выполняет и проверяет результат.
- **Файлы в чате**: кнопка 📎, перетаскивание в окно, Ctrl+V для картинок. Фото, сканы (включая PDF без
  текстового слоя), Word, Excel, PowerPoint и другие форматы библиотеки.
- **Зрение**: та же модель Qwen3.5-4B читает фото и сканы (дополнительный файл `mmproj`, 0,6 ГБ) —
  текст и таблицы переводятся в электронный вид, сохраняются в Word и Excel.
- **Проверка по нормативам**: требования ищутся в библиотеке, каждое подтверждается дословной цитатой,
  числа («не менее», «от … до») сравнивает программа.
- **Документ по образцу**: новый документ той же формы, что образец из библиотеки, по данным из файла;
  DOCX в оформлении образца.
- **Сравнение редакций**: построчные различия находит программа, модель описывает изменения.
- **Перевод, пересказ, письма и служебные записки** по файлам и предыдущим ответам.
- **Голос**: 🎤 — запрос голосом (whisper large-v3-turbo на видеокарте), 🔊 — ответ голосом (Piper),
  голосовой диалог без клавиатуры.
- **Команды на компьютере**: ассистент предлагает команды PowerShell, выполнение — только по кнопке
  и с повторным предупреждением для опасных команд.
- **Личные инструкции**: постоянные правила для всех ответов (подпись, стиль, реквизиты).
- **Файлы в ответах**: Открыть / Сохранить как / В папке / В библиотеку.

## Проверки качества (программа, не модель)

- арифметика распознанных таблиц (количество × цена = сумма, итог = сумма столбца, среднее);
- каждое число и дата в новых документах, письмах и сравнениях сверяется с исходными данными,
  несовпадения отмечаются ⚠ (в том числе значения, перенесённые из образца);
- требования норматива — только с дословной цитатой; вывод модели пересчитывается по числам.

- Распознавание фото: шесть «снимков с телефона» (протокол с таблицей, анализ, рукописный журнал, счёт,

- Голос: распознавание фразы 0,2–0,4 с (первый запуск ~2 с), озвучивание ~0,5 с.
- Команды из набора выполнялись на самом деле и дали верный результат (свободное место, версия Windows, IP).

## Известные ограничения

- Модель 4B иногда путает похожие разделы длинных документов (см. 1.10.1) — для ответов по библиотеке это не изменилось.
- Проверка по нормативам находит требования, только если они есть в библиотеке текстом; нормы в виде
  картинок или сканов нужно один раз распознать (приложить и нажать «В библиотеку»).
- Распознавание фото рассчитано на печатный текст и аккуратный почерк; неразборчивый почерк и мелкий
  шрифт на плохом фото дают ошибки — для таблиц их выдаёт проверка арифметики (⚠).
- Похожие буквы и цифры (З/3, латинские/кириллические буквы) на фото могут путаться.
- Команды PowerShell проверяются на синтаксис и существование, но не на смысл: читайте предложенную
  команду перед выполнением.
- Аудиофайлы проверены в формате WAV.
- Голос и зрение занимают видеопамять: на 8 ГБ всё помещается (~7 ГБ при голосе), на 6 ГБ голос лучше не включать.
