# ChatKodi 1.8.0-rc7

Итерация сфокусирована на автоматизации установки, общей оптимизации повторных запусков и подготовке дороги к 1.9.

## Главное

- Добавлен `INSTALL_LAUNCHER.bat` и `START_HERE.bat`.
- Минимальная установка теперь ставит только лаунчер, а полную подготовку делает сам лаунчер.
- Добавлен `requirements-launcher.txt` для лёгкого старта.
- Добавлен `requirements-app.txt`, чтобы автоматическая установка не ставила PyTorch два раза.
- В лаунчер добавлена кнопка `Подготовить и запустить`.
- Автоподготовка теперь пропускает лишнюю загрузку моделей, если они уже есть.
- PyTorch ставится по CPU/CUDA-ветке только когда он отсутствует или не соответствует найденной CUDA.
- Обновлены manuals по установке и автоматизации.

## Зачем это сделано

Пользователь должен пройти путь:

```text
Запустил START_HERE.bat → открылся лаунчер → нажал «Подготовить и запустить» → получил рабочий ChatKodi
```

Ручные скрипты и вкладки остаются, но теперь это запасной путь, а не основной сценарий.
