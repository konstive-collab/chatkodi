# ChatKodi 1.7.9-rc1 — Section-scoped analytics hotfix

## Что исправлено

- Для документов с секциями вида `рБпЛА №11 (Изюмское направление):` добавлена section-aware обработка.
- Статистика по запросам к конкретной сущности больше не считается по всему документу только потому, что документ попал в дату/период.
- Вопросы вида `На каком направлении работал рБпЛА №11 с ... по ...` должны возвращать направление секции, а не все направления из итоговых абзацев документа.
- Событийный индекс `events.db` автоматически пересобирает записи из-за bump signature `section-aware-v2`.
- Направления нормализуются: `Изюмском` / `Изюмский` -> `Изюмское`.
- Для range/statistics запросов добавлена более строгая object-scope фильтрация.

## Почему это важно

Раньше диапазонная статистика могла брать все события из документов 10–12 июня, даже если пользователь спрашивал только про `рБпЛА №11`. Это давало лишние направления, завышенные счётчики и повторяющиеся паттерны.

Теперь единица анализа для таких запросов — релевантная секция внутри документа.
