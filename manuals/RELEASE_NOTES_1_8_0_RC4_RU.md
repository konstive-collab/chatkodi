# ChatKodi 1.8.0-rc4

Эта сборка — полировка интерфейса, лаунчера и загрузки LLM.

## Главное

- Добавлены три темы: **Классическая**, **Тёмная**, **Светлая**.
- Тема теперь общая для лаунчера, экрана загрузки и основной программы.
- Лаунчер стал понятнее: Авто остаётся основным сценарием, ручные настройки спрятаны как дополнительная возможность.
- Добавлена кнопка **Вернуть всё в Авто**.
- Перед запуском без LLM лаунчер предупреждает, что уточняющие вопросы по данным не будут работать.
- Исправлен поиск sharded LLM-моделей Hugging Face.
- Мануалы расширены: запуск, лаунчер, темы, LLM-диагностика.

## Зачем это нужно

Обычный пользователь должен получить рабочий запуск за пару кликов: подготовить автоматически → запустить. Всё остальное — для тех, кто хочет докрутить вручную.
