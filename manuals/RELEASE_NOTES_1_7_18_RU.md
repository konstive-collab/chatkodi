# Release notes: ChatKodi 1.7.18-rc1

## Главное

1. Добавлена расширенная поддержка популярных форматов документов.
2. В чанки добавлены координаты `start_char`, `end_char`, `line_start`, `line_end`.
3. EventStore теперь получает координаты фрагментов и сохраняет их в metadata.
4. В интерфейс добавлены мягкие анимации переключения рабочих областей, предпросмотра документа и раскрытия источников.
5. Диалог добавления документов теперь показывает расширенный фильтр форматов.

## Новые форматы

Поддерживаются текстовые файлы, HTML, EPUB, DOCX, DOC, RTF, ODT/ODS/ODP, XLSX/XLSM/XLS, PPTX/PPT, PDF и ряд технических текстовых форматов.

Старые `.doc`, `.ppt` и битые бинарные файлы читаются best-effort. Для лучшего качества на Windows можно открывать/пересохранять такие файлы в `.docx`/`.pptx`, а на Linux ставить `antiword` или `catdoc`.

## Важное после обновления

Из-за добавления координат и нового формата metadata лучше удалить старую структурную базу и переиндексировать документы:

```text
.chatkodi/events.db
.chatkodi/events_meta.json
```

`models_cache` удалять не нужно.
