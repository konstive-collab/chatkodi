# Кнопка «Спросить по данным»

Начиная с `1.7.19-rc1` под каждым ответом ChatKodi появляется аккуратная зелёная кнопка **«Спросить по данным»**.

## Зачем это нужно

Обычный вопрос в RAG-режиме заново запускает поисковую цепочку: анализ запроса, поиск по документам, сбор контекста, структурную проверку и генерацию ответа. Это правильно для нового вопроса, но неудобно для уточнений вроде:

- «а какие дни самые насыщенные?»
- «сделай вывод короче»
- «почему ты считаешь активность регулярной?»
- «покажи только документы за 12–15 число»

В таких случаях пользователь уже смотрит на найденный ответ и хочет спросить именно по нему, а не заставлять систему заново искать по всей базе.

## Как работает

1. Пользователь нажимает **«Спросить по данным»** под нужным ответом.
2. ChatKodi раскрывает небольшое поле ввода прямо внутри сообщения.
3. Пользователь вводит уточняющий вопрос.
4. В LLM передаётся только текст выбранного ответа как временный контекст.
5. Новый поиск по корпусу не запускается.

Это не долговременная память диалога. ChatKodi не запоминает весь разговор и не начинает смешивать старые ответы с новыми. Контекст живёт только в рамках одного уточняющего вопроса.

## Почему это безопаснее для точности

Кнопка помогает избежать ситуации, когда уточнение случайно уводит поиск в соседние документы или похожие, но нерелевантные фрагменты. Если пользователь уточняет уже найденную сводку, система отвечает только по этой сводке.

Если в выбранном ответе нет нужной информации, ChatKodi должен честно сказать, что в этих данных этого нет.

## Ограничения

- Для полноценного ответа нужна локальная LLM.
- Кнопка не заменяет новый поиск, если пользователь хочет найти дополнительную информацию в документах.
- Если исходный ответ был слишком коротким или неточным, уточнение наследует эти ограничения.
