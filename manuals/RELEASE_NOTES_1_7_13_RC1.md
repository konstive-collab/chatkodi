# ChatKodi 1.7.13 RC1 — readable verified answers

Главная цель: сделать structured-ответы понятными для человека и снизить риск ложной уверенности.

## Изменения

- Короткий человекочитаемый ответ теперь является режимом по умолчанию.
- Подробные цифры показываются только по явному запросу: «статистика», «подробно», «таблица», «сколько», «как часто».
- Запросы «проанализируй» больше не превращаются автоматически в большую числовую простыню.
- Частотные/сводные ответы стали компактнее: вывод → 1–2 ключевых среза → подтверждения.
- Исправлено дублирование строки дат в подробной статистике.
- Добавлены предупреждения при малом количестве данных или сильной фильтрации.

## Как тестировать

- Обычный вопрос: `Какие цели поражены изделием-51 с 10 по 15 июня 2025 года?` — должен дать список целей без перегруза цифрами.
- Подробный вопрос: `Покажи подробную статистику по целям...` — должен показать цифры и документы-основания.
- Анализ: `Проанализируй работу ...` — должен дать краткий вывод, а не длинную бухгалтерскую сводку.
