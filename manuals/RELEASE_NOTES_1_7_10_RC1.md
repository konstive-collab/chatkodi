# ChatKodi 1.7.10 RC1 — Target Listing & Range Evidence Fix

Фокус сборки: вопросы вида «Какие цели поражены ... за период?» и корректная выдача документов/дат в диапазонной статистике.

## Исправлено

- Добавлен отдельный тип вопроса `target` для запросов про цели/объекты поражения.
- Вопросы «какие цели», «какие объекты», «что было поражено» больше не уходят в широкий `range_summary`.
- Для target-запросов answer builder теперь сразу перечисляет цели, даты, средство/способ и источники.
- Range/statistics pipeline больше не отбрасывает документы, если их нашёл `EventStore`, но они не попали в top-doc retrieval.
- Список «Использованные документы» для structured-ответов теперь строится по фактическим evidence-записям, а не только по top-doc поиску.
- `top_dates` и `top_sources` расширены, чтобы не терять последний день периода вроде 15 июня.
- Для target-запросов из статистики отсекаются записи без явно выделенной цели.
- Формат счётчиков стал понятнее: `цель — N упомин`, вместо неясных скобок.

## Ожидаемый эффект

Запрос:

```text
Какие цели поражены изделием-51 с 10 по 15 июня 2025 года?
```

теперь должен давать прямой ответ в стиле:

```text
Поражённые цели изделием-51 за период 2025-06-10 — 2025-06-15: ...
По датам: ... 2025-06-15 ...
Использованные документы: 10.docx ... 15.docx
```

а не общую сводку «Найдено N ключевых упоминаний».
