# Где что лежит

`manuals/` — справка по программе. Эти файлы не должны индексироваться как пользовательские данные.

`docs/` — пользовательский корпус документов. Если пользователь хочет быстро начать, он кладёт файлы сюда.

`scripts/windows/` — готовые команды для Windows.

`tools/` — Python-утилиты для разработчика и лаунчера.

`.chatkodi/` — runtime-данные: индексы, базы, настройки, логи, support bundle.

`models_cache/` — модели. В новых версиях предпочтителен `.chatkodi/models_cache`, но старый `models_cache/` поддерживается ради совместимости.
