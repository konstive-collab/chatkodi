# Что делать, если LLM не загрузилась

LLM нужна для ответов своими словами, пересказов и кнопки **Спросить по данным**. Поиск документов
и точные ответы (даты, суммы, госномера, подсчёты) работают и без неё.

## Проверка №1: не включён ли режим без LLM

В лаунчере на вкладке **Модели** должно быть выбрано **Авто**. Не выбирайте
**Только поиск — не загружать LLM**, если хотите задавать вопросы своими словами.

## Проверка №2: целостность файлов

Запустите `VERIFY_CHATKODI.cmd` из папки программы. Он сверяет все файлы, включая модели
и `llama.cpp\...\llama-server.exe`. Результат дописывается в `runtime\logs\portable_preflight.log`.
Если есть ошибки — скопируйте папку из архива заново.

## Проверка №3: журнал сервера модели

Откройте `runtime\logs\llama_server_llm.log`. Частые причины:

- `out of memory` / `failed to allocate` — не хватило видеопамяти или ОЗУ. Закройте программы,
  которые используют видеокарту (игры, браузер с аппаратным ускорением), и перезапустите ChatKodi.
- `failed to load model` — файл модели повреждён: см. проверку №2.
- сообщение о драйвере или CUDA — обновите драйвер NVIDIA (нужна поддержка CUDA 12: версия 527 или новее).
  Без видеокарты NVIDIA модель работает на процессоре, но медленнее.

## Проверка №4: файл подкачки Windows

Если в журнале или в окне программы есть `WinError 1455` / «файл подкачки слишком мал»,
включите «Размер по выбору системы» для файла подкачки и перезапустите компьютер.

## Если всё равно не работает

Создайте **Support bundle** в лаунчере и приложите:

- `runtime\logs\chatkodi.log`;
- `runtime\logs\llama_server_llm.log` и `runtime\logs\llama_server_embeddings.log`;
- `runtime\logs\portable_preflight.log`.
