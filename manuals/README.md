# Документация ChatKodi 1.7.17-rc1

Эта папка описывает внутреннюю логику программы простым инженерным языком: как ChatKodi ищет документы, извлекает факты, считает статистику, строит отчёты и показывает источники.

## Что читать в первую очередь

1. `PROJECT_LOGIC_RU.md` — общий путь вопроса через систему.
2. `UNIVERSAL_FACT_MODEL_RU.md` — универсальная модель знания: упоминание, сущность, факт, параметр, источник.
3. `STATISTICS_LOGIC_RU.md` — почему статистика больше не должна считать «чанки» вместо фактов.
4. `ACTIVITY_REPORT_RU.md` — режим «подробная работа X за период».
5. `SOURCE_BUTTONS_RU.md` — выпадающий список источников с кнопками «Показать» и «Открыть».
6. `DEBUGGING_RU.md` — диагностика, кэши, логи, пересборка индекса.
7. `ROADMAP_NEXT_ITERATIONS_RU.md` — ближайшие инженерные итерации.

## Главный принцип версии

ChatKodi должен отвечать не красивым пересказом похожих фрагментов, а доказательными утверждениями. Если единица счёта не определена, статистика не имеет права выглядеть уверенной.

- `CONTEXT_ASK_RU.md` — логика кнопки «Спросить по данным» и уточняющих вопросов по выбранному ответу.
