# ChatKodi 1.9.1 — исправления по итогам тестирования

## Запуск на любом ПК

- **Проверка целостности portable-папки больше не блокирует запуск из-за некритичных файлов.**
  Отсутствующие `manuals/*.md`, дубликаты DLL во вложенных папках библиотек и правки манифеста
  записываются как предупреждения в `runtime/logs/portable_preflight.log`. Старт блокируется только
  при повреждении самой программы или embedding-модели (без неё не работает поиск).
  Если повреждены файлы LLM, программа запускается в режиме «только поиск» и пишет причину.
  Переменная `CHATKODI_SKIP_PORTABLE_VERIFY` больше не нужна.
- «Критичность» по имени файла теперь действует только в корне и в верхнем уровне `_internal`:
  копия `vcruntime140.dll` внутри `sklearn/.libs` и т.п. больше не считается критичной.
- **Сборка:** манифест генерируется последним шагом из финальной папки `release/ChatKodi`,
  а zip-архив собирается самой сборкой (`--make-zip`) с проверкой, что в архив попал каждый файл
  манифеста с правильным размером. Имена в архиве — UTF-8, разделитель `/`.
  Распространяйте именно этот архив, а не папку, заархивированную вручную.

## Загрузка модели (os error 1455, segfault)

- Перед загрузкой LLM оценивается нужный объём виртуальной памяти (ОЗУ + файл подкачки):
  самый крупный shard + слои, не помещающиеся в видеопамять, + запас. Если не хватает —
  модель не грузится, а пользователь получает понятную инструкцию по файлу подкачки.
- Ошибка `WinError 1455 / os error 1455` переводится в человеческий текст вместо traceback.
- Если загрузка модели аварийно завершила процесс (segfault), следующий запуск это распознаёт
  и не повторяет падение: автозагрузка отключается, пока не вырастет свободная виртуальная память
  (или пока пользователь явно не включит LLM в лаунчере).
- В «Авто» на видеокарте выбирается самая крупная модель, которая помещается в видеопамять
  (допускается ~20% выгрузки). Если модель не помещается, после загрузки показывается
  предупреждение: сколько слоёв работает на CPU и какой размер модели подойдёт лучше.

## LLM и память

- `token_budget_guard` больше **не запрещает** LLM: если контекст больше бюджета железа,
  он сокращается до самых релевантных строк, а модель работает.
- Большой корпус (много найденных документов) больше не отключает LLM — размер корпуса
  не влияет на размер промпта.
- Бюджет применяется и к доказательствам grounded-ответа (раньше в модель уходило до 18 000 символов
  в обход защиты).
- Режим «Фрагменты» стал режимом по умолчанию. В режиме «Целые документы» длинный документ
  больше не обрезается по началу — в контекст попадают строки, относящиеся к вопросу.
- Если LLM не ответила, сообщение называет настоящую причину: не загружена (и почему),
  отключена политикой памяти (и как включить), ошибка генерации.

## Качество и скорость поиска

- **Точные ответы из документов без LLM** (миллисекунды): значение по дате
  («какая выручка 5 августа 2025»), строка таблицы по госномеру («кто был водителем …»),
  состав смены и т.п. Ответ показывает точную строку-подтверждение и документ.
  «План», «прогноз», «норматив» не выдаются за фактическое значение, если о них не спрашивали.
- **Вопросы по многим документам**: «сколько дней работал Иванов И.И. в июле»,
  «в какие дни выезжал автомобиль А123ВС 77» — подсчёт проходом по всем документам периода
  со списком дат и источников. Отметки «в отпуске / отсутствовал / больничный» не засчитываются,
  документы без даты перечисляются отдельно.
- Значения за период: «сколько всего отгружено в марте» — по дням, итог, минимум/максимум.
- **Поиск по госномеру больше не ждёт минутами**: служебный LLM-роутер вопросов получил настоящий
  таймаут и отключается до перезапуска, если железо стабильно не успевает.
- Проверка соответствия ответа вопросу: если ответ LLM расходится со значением, найденным в документе,
  показывается значение из документа.
- Исправлена загрузка DOCX: инициалы больше не разрываются («Иванов И.П.» оставался «Иванов И.»).
- Строки таблиц DOCX/XLSX/CSV сохраняют заголовки столбцов («Госномер: … | Водитель: …»),
  поэтому строка понятна даже отдельно от шапки таблицы.
- Даты: «в августе 2025», «в июле», «в 2025 году» понимаются как период; если год не указан,
  берётся год, за который есть документы.
- Недоступное внешнее векторное хранилище больше не роняет индексацию — используется локальный индекс.
