# ChatKodi 2.0.0 — ассистент действует сам, новый облик окна, несколько чатов

Окно осталось узнаваемым — те же цвета, раскладка и зелёный акцент, — но стало современнее и удобнее,
а ассистент — самостоятельнее: сам решает, что делать, составляет план, работает с файлами
на компьютере и с другими программами. Всё по-прежнему работает на одном компьютере без интернета.

## Ассистент действует сам

- **Никаких режимов.** Переключатель «Поиск / Ассистент» убран: ассистент сам понимает, нужен ли ответ
  по библиотеке, работа с файлом, документ, команда или действие в программе.
- **План, когда он нужен.** Если в запросе несколько задач («проверь протокол по нормативам и оформи
  заключение по образцу»), ассистент составляет план и выполняет шаги по очереди — каждый следующий
  работает с результатом предыдущего. Простую задачу он делает сразу, без плана.
- **Самостоятельность — в настройках**: «Только с разрешения» (по умолчанию), «Автомат» (обычные действия —
  сам, о рискованных спрашивает), «Полная самостоятельность». Чтение и поиск не требуют подтверждения никогда;
  необратимое (удаление, форматирование, работа с дисками) подтверждается **всегда**, при любой настройке.
  Риск определяет программа по самим командам, а не только модель.
- **Файлы на компьютере**: «найди акт приёмки», «приложи договор поставки к чату», «скопируй в библиотеку»,
  «переименуй…», «перенеси в папку…». Сначала поиск в библиотеке, затем на Рабочем столе, в Документах,
  Загрузках и в папках, добавленных в настройках. Найденное — карточками с кнопкой «Приложить к чату».
  Переименование и перенос никогда не перезаписывают файлы и отменяются кнопкой «Отменить».
- **Другие программы**: черновик письма в Outlook с вложенными документами (без Outlook — в почтовой
  программе по умолчанию); письмо **никогда не отправляется само** — его отправляете вы. Открыть файл
  в Word/Excel, запустить программу.
- **Память между чатами**: ассистент запоминает устойчивые факты (кто вы, организация, постоянные адресаты,
  «запомни …») и учитывает их во всех чатах. Список — «Настройки → Память…»: удалить, добавить, очистить;
  память можно выключить.

## Оформление

- Собственные шрифты: Onest (интерфейс) и Unbounded (логотип) — свободная лицензия SIL OFL, встроены в программу.
- Боковая панель: «Новый чат», поиск по чатам, список чатов; разделы (Документы, База и индекс,
  Диагностика, Настройки) — компактным списком; внизу живые диаграммы ресурсов ПК: процессор, память,
  загрузка видеокарты, видеопамять и график нагрузки за 90 секунд.
- Тонкая строка над чатом с названием чата вместо двух больших панелей.
- Диаграммы ресурсов ПК свёрнуты и раскрываются по клику «Ресурсы ПК».
- Сообщения подстраиваются под длину текста — без пустых полей.
- Таблицы и блоки кода в ответах отображаются как таблицы и код.

## Несколько чатов

- Каждый чат хранит свою переписку, вложения и память ассистента. Название появляется само по первому вопросу
  (или по имени файла), его можно изменить; чаты можно закреплять и удалять (правый клик).
- Отметка у чата: ✓ — всё проверено, ! — есть несоответствия или замечания.
- Поиск ищет и по названиям, и по тексту переписки. Прежняя история 1.11 стала первым чатом.

## Ответ ассистента

- **Ход работы**: пока ассистент работает, текущий шаг переливается («Распознаю изображение… 2,4 с»),
  готовые шаги отмечаются ✓. Потом всё сворачивается в строку «Ход работы · 3 шага · 7,4 с», по клику — подробности.
- **Ответ печатается по словам**, а кнопки и файлы появляются, когда текст готов.
- **Файлы — карточками**: миниатюра (фото, первая страница PDF или начало документа), тип, размер и итог:
  «распознано · арифметика ✓» или «⚠ проверьте цифры».
- **Созданный документ — листом бумаги**: левый клик — скачать, правый — развернуть по листам прямо в чате;
  там же «Править текст» — исправления сохраняются в тот же файл (в оформлении образца).
- **Подсказки следующего шага**: под ответом модель предлагает 2–3 логичных продолжения по смыслу
  разговора («Проверь по нормативам», «Оформи заключение по образцу»…) — один клик вместо набора.
- **Цитата в документе**: «Источники ответа → Показать» открывает документ справа от чата, нужное место
  подсвечено и прокручено; «Следующая» — к другим цитатам.

## Голос

- Пока вы говорите, над полем ввода — плавная волна от реального уровня микрофона, а текст появляется в поле
  по ходу речи; после паузы запрос отправляется сам.

## Удобство

- **Перетаскивание**: файл над окном — чат затеняется, рамка и «Отпустите — приложу к чату».
- **Ctrl+K**: одно окно для действий, чатов и документов библиотеки; стрелки, Enter, Esc, подсказки клавиш.
  Также Ctrl+N — новый чат, Ctrl+O — приложить файл, Ctrl+M — голос, Ctrl+, — настройки.

## Настройки модели и ассистента

Раздел «Настройки» → «Модель и ассистент»: творчество в письмах и разговоре (ответы по документам всегда строгие),
длина ответов, объём контекста, видеокарта или процессор, зрение, голос (Ирина/Дмитрий), голосовой ввод,
самостоятельность, команды PowerShell, подсказки, печать по словам, память между чатами; кнопки «Личные инструкции…»,
«Память…», «Папки для поиска…». Пункты со звёздочкой применяются после перезапуска — кнопка «Перезапустить ChatKodi».

## Известные ограничения

- Подсказки следующего шага предлагает модель — изредка они бывают неточными (например, предлагают то,
  для чего в библиотеке нет документов).
- Модель 4B иногда выбирает не тот путь для вопроса «можно ли …» по приложенному файлу и правилам библиотеки
  и отвечает противоречиво (так в 1 из 40 сценариев: счёт выше лимита). Надёжнее спросить прямо:
  «проверь этот счёт по нашим правилам» — тогда вывод проверяет программа.
- Поиск файлов на компьютере идёт по именам файлов и папок (поиск по содержимому — в библиотеке);
  на очень больших дисках он ограничен несколькими секундами.
- Работа с произвольными программами через их окна (клики по интерфейсу) пока не поддерживается —
  только Outlook, открытие файлов и запуск программ.
- Текст при голосовом вводе обновляется примерно раз в секунду (распознаётся всё сказанное заново).
- Правка документа в чате сохраняет текст, таблицы, заголовки и жирный шрифт; сложное оформление
  (колонтитулы, картинки) берётся из образца, но вставить новые картинки из чата нельзя.
