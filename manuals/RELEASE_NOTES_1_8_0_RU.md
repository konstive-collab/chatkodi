# Release Notes — ChatKodi 1.8.0-rc1

## Крупные изменения

- Перенос документации приложения из `docs/` в `manuals/`.
- `docs/` теперь считается пользовательской папкой корпуса.
- Добавлен `launcher.py` и пакет `tools/launcher/`.
- Добавлены PowerShell-скрипты установки и запуска в `scripts/windows/`.
- Добавлены root-обёртки `INSTALL_WINDOWS.bat`, `START_LAUNCHER.bat`, `START_CHATKODI.bat`.
- Добавлен модуль `core/search_preferences.py`.
- Добавлены UI-настройки: режим запроса и строгость поиска.
- Добавлена кнопка `Почему такой ответ?` под AI-ответами.
- Правая панель теперь показывает краткий trace: тип запроса, бюджет evidence, режим контекста, количество выбранных документов/фрагментов.

## Что ещё требует проверки

- Полный запуск GUI на Windows.
- Установка PyTorch CUDA на реальной машине с NVIDIA.
- Поведение лаунчера на чистой системе без PyQt5.
- Регрессия точных запросов по рБпЛА/изделиям/датам.
- Проверка, что `manuals/` не попадает в индекс при выборе корня проекта.

## Рекомендация после обновления

Удалите старые структурные индексы и переиндексируйте документы:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\windows\reset_index.ps1
```

`models_cache` не удаляется.
