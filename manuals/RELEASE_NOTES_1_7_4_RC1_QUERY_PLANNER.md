# ChatKodi 1.7.4-rc1 — Query Planner

## Что добавлено
- безопасный `QueryPlanner`, который использует LLM только для выбора режима ответа
- planner не отвечает пользователю и не подменяет доказательства/статистику
- fallback на старую rule-based логику при любой ошибке или низкой уверенности
- в `intent_meta` и support bundle добавлены поля о маршрутизации

## Принцип
1. rules-first разбор остаётся базой
2. planner включается только для более сложных/диапазонных/статистических запросов
3. planner возвращает строгий JSON
4. итоговый поиск, подсчёты и evidence по-прежнему делает код

## Зачем
- уменьшить зависимость от хрупких слов-триггеров
- лучше различать fact / range / statistics / comparison
- не ломать существующую логику поиска и structured-ответов
