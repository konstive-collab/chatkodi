# Работа с моделями (ChatKodi 2.1)

С версии 2.0 обе модели работают в **llama.cpp** (программа `llama-server`) в формате **GGUF**.
PyTorch, transformers и sentence-transformers программе больше не нужны.

| роль | модель | файл | размер |
|---|---|---|---|
| ответы на вопросы (LLM) | Qwen3.5-4B, квантование Q4_K_M | `Qwen3.5-4B-Q4_K_M.gguf` | 2,7 ГБ |
| поиск по смыслу (эмбеддинги) | Qwen3-Embedding-0.6B, Q8_0 | `Qwen3-Embedding-0.6B-Q8_0.gguf` | 0,6 ГБ |
| зрение LLM: фото и сканы | проектор Qwen3.5-4B, F16 | `mmproj-Qwen3.5-4B-F16.gguf` | 0,6 ГБ |
| распознавание речи | whisper large-v3-turbo, q5_0 (whisper.cpp) | `speech\ggml-large-v3-turbo-q5_0.bin` | 0,55 ГБ |
| синтез речи | Piper, голоса Ирина и Дмитрий | `speech\voices\ru_RU-*.onnx` | 2 × 60 МБ |

- Модель эмбеддингов обязательна: без неё не строится индекс и поиск не запустится.
- LLM нужна для ответов своими словами, пересказов и проверенных ответов с цитатами.
  Без неё работает поиск и точные ответы из документов (даты, суммы, госномера, подсчёты).

## Где лежат файлы

В portable-архиве:

```text
ChatKodi\
├─ models_cache\
│  ├─ llms\Qwen3.5-4B-Q4_K_M.gguf
│  ├─ llms\mmproj-Qwen3.5-4B-F16.gguf      (зрение: фото и сканы)
│  ├─ embeddings\Qwen3-Embedding-0.6B-Q8_0.gguf
│  └─ speech\                               (голос, необязательно)
│     ├─ whisper\whisper-server.exe (+ ggml)
│     ├─ ggml-large-v3-turbo-q5_0.bin
│     ├─ piper\piper\piper.exe
│     └─ voices\ru_RU-irina-medium.onnx, ru_RU-dmitri-medium.onnx
└─ llama.cpp\b11669-cuda12.4\llama-server.exe (+ библиотеки ggml и CUDA)
```

Программа сама запускает два фоновых `llama-server` (по одному на модель) на свободных портах
`127.0.0.1` и останавливает их при выходе. Журналы серверов: `runtime\logs\llama_server_llm.log`
и `runtime\logs\llama_server_embeddings.log`.

## Как выбирается LLM

- Если в `models_cache\llms\` несколько GGUF-файлов, выбирается Qwen3.5-4B, если она помещается
  в видеопамять; иначе — самая крупная из помещающихся. Без видеокарты NVIDIA — самая маленькая.
- Резерв видеопамяти рассчитан по замерам: кэш контекста и буферы ~0,9 ГБ, сервер эмбеддингов ~1,5 ГБ,
  рабочий стол Windows ~1,3 ГБ. Модель, которая не помещается, Windows молча выгружает в обычную память,
  и ответы замедляются в несколько раз.
- Модель можно указать вручную: переменная `CHATKODI_MODEL_PATH` (путь к `.gguf`-файлу).
- Отключить LLM: `CHATKODI_DISABLE_LLM=1` (останется поиск и точные ответы).

## Видеокарта и процессор

- При наличии видеокарты NVIDIA модели работают на ней (CUDA 12, драйвер NVIDIA 527 или новее).
  llama.cpp сам распределяет слои по свободной видеопамяти (`--fit`).
- Без видеокарты всё работает на процессоре, но ответы LLM заметно медленнее.
- Эмбеддинги можно принудительно перевести на процессор: `CHATKODI_EMBEDDINGS_DEVICE=cpu`.

## Почему Qwen3.5-4B, а не 9B

На тестовом наборе вопросов по отчётам 4B ответила верно на 22 из 22, 9B — на 16 из 22
(9B чаще отвечала «подтверждение не найдено» там, где в отчёте прямо написано «в штатном режиме»).
На видеокарте 8 ГБ 9B к тому же не помещается вместе с моделью эмбеддингов и работает в ~6 раз медленнее.

## Проверка файлов

- `VERIFY_CHATKODI.cmd` — сверяет все файлы с манифестом, модели и `llama-server` — по SHA-256.
- Повреждённая или недокачанная LLM не мешает запуску: программа работает без неё и сообщает об этом.
  Повреждённая модель эмбеддингов или файлы `llama.cpp` блокируют запуск с понятным сообщением.
- Голос необязателен: без папки `speech` или при повреждённых файлах программа работает, кнопки 🎤/🔊 сообщают причину.
- Без файла `mmproj` фото и сканы не распознаются (документы с текстом читаются как обычно).

## Зрение и голос

- Зрение — это та же Qwen3.5-4B: файл `mmproj` подключается к серверу LLM (`--mmproj`), вторая модель не нужна.
  Отключить: `CHATKODI_DISABLE_VISION=1`; другой проектор: `CHATKODI_MMPROJ_PATH`.
- Распознавание речи — отдельный `whisper-server` на видеокарте, запускается при первом нажатии 🎤
  (CUDA-библиотеки общие с llama.cpp). Журнал: `runtime\logs\whisper_server.log`.
- Синтез речи — Piper на процессоре, ~0,5 с на фразу.
