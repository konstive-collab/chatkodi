# Настройки поиска в ChatKodi 1.8

В верхней панели чата появились две настройки.

## Режим запроса

- `Авто` — ChatKodi сам определяет тип вопроса.
- `Точный факт` — лучше для вопросов «было ли», «где», «когда», «чем».
- `Подробный отчёт` — для вопросов вида «подробная работа X за период Y».
- `Статистика` — для подсчётов, периодичности, распределения по датам и документам.
- `Поиск документов` — не генерирует общий RAG-ответ, а показывает найденные документы/фрагменты.

## Строгость

- `Строго` — меньше документов и фрагментов, жёстче привязка к объекту/дате/действию.
- `Сбалансированно` — режим по умолчанию.
- `Шире` — больше кандидатов и больше контекста. Полезно для свободного текста.

## Почему это не ломает универсальность

Настройки не зашивают предметную область. Они регулируют единицу работы поиска: насколько широко собирать evidence и как показывать результат. Поэтому один и тот же механизм подходит для сводок, рецептов, лекций, таблиц и технических логов.
