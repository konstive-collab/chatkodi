# Установка лаунчера ChatKodi

Начиная с `1.8.0-rc7` установка разделена на два спокойных шага.

## Самый простой вариант

1. Распакуйте архив ChatKodi в удобную папку.
2. Запустите `START_HERE.bat` или `INSTALL_LAUNCHER.bat`.
3. Скрипт найдёт Python 3.10+ или попробует поставить Python 3.11 через `winget`.
4. Скрипт создаст `.venv` и установит только зависимости лаунчера: PyQt5, psutil, huggingface-hub.
5. После этого откроется ChatKodi Launcher.

## Что делать в лаунчере

Обычный сценарий — одна большая кнопка:

```bat
Подготовить и запустить
```

Она делает полную подготовку приложения: ставит библиотеки, проверяет модели, скачивает недостающее и запускает ChatKodi.

Если нужно разделить процесс, используйте:

```bat
Только подготовить
Запустить ChatKodi
```

## Почему установка разделена

Раньше полный установщик сразу тянул тяжёлые зависимости и модели. Если что-то ломалось, пользователь видел длинную консоль и не понимал, что произошло. Теперь сначала ставится лёгкий лаунчер, а уже в нём видно состояние системы, модели, профили и логи.

## Ручной запуск команд

Минимальный лаунчер:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows\install_launcher.ps1
```

Полная старая установка без GUI:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows\install_all.ps1
```

Запуск лаунчера после установки:

```bat
START_LAUNCHER.bat
```
