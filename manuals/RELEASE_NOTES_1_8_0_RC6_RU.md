# ChatKodi 1.8.0-rc6

Фокус версии: вернуть ощущение скорости и собрать внешний вид трёх окон в один дизайн.

## Главное

- Главное окно, лаунчер и экран загрузки теперь используют единую палитру из `core/theme_manager.py`.
- В главном окне добавлен компактный переключатель темы в правом верхнем углу чата: классическая, тёмная, светлая.
- Тема, выбранная в лаунчере, теперь имеет приоритет над старым файлом настроек главного окна.
- Исправлена маршрутизация RAG + lazy LLM: unloaded lazy-LLM больше не считается «готовой» для streaming. Это защищает слабые CPU-машины от внезапной загрузки многогигабайтной модели при обычном вопросе по документам.
- Streaming-буфер обновляется чуть реже, чтобы снизить нагрузку на интерфейс во время генерации.
- Анимации стали адаптивными: на очень слабом профиле интерфейс не тратит лишнее время на fade-эффекты.
- Экран загрузки получил цвета из общей палитры, включая консоль загрузки.

## Почему это важно

На CPU с 8 GB RAM тяжёлая LLM может грузиться минутами. В rc6 ChatKodi сначала пытается дать структурный/direct ответ по документам, а LLM подключает только когда это действительно нужно. Обычный пользователь получает быстрый поиск, а ручной выбор тяжёлой модели всё ещё остаётся доступным через лаунчер.

## Рекомендация после обновления

Запускать через:

```bat
START_LAUNCHER.bat
```

В лаунчере оставить профиль и модель в режиме `Авто`, если нет необходимости вручную форсировать конкретную модель.
