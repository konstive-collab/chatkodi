# ChatKodi 1.8.0-rc5

Главная цель rc5 — вернуть скорость и стабильность после расширения интерфейса, лаунчера и тем.

## Исправлено

- RAG-вопросы больше не заставляют LLM грузиться заранее перед поиском.
- `Спросить по данным` больше не грузит LLM в GUI-потоке.
- Режим `Авто` больше не выбирает тяжёлую LLM на CPU/low-RAM устройстве, если это может привести к многоминутной загрузке.
- Ручной выбор модели в лаунчере сохраняет контроль: если пользователь выбрал тяжёлую модель сам, ChatKodi попробует её использовать.
- Проверка модели учитывает sharded-веса `model-00001-of-00003.safetensors`.
- Для CPU-загрузки модель больше не форсируется в `float32`, что уменьшает риск лишнего расхода RAM.

## Что это даёт

На слабом ПК основной сценарий снова должен быть быстрым: поиск, структурные ответы, источники, статистика и отчёты работают без обязательной загрузки большой LLM.

LLM остаётся доступной, но включается только когда реально нужна: обычный чат, свободная генерация, уточнение по данным, если нет структурного ответа.
