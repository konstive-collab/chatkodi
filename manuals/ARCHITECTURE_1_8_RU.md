# Архитектура ChatKodi 1.8

## Папки верхнего уровня

- `main.py` — вход в основное desktop-приложение.
- `launcher.py` — вход в графический лаунчер.
- `core/` — ядро: документы, поиск, RAG, LLM, статистика, факты, события, диагностика.
- `gui/` — интерфейс основного приложения.
- `tools/` — инженерные утилиты: doctor, bootstrap, support bundle, model manager, launcher.
- `scripts/` — команды запуска и установки, особенно для Windows.
- `manuals/` — документация программы.
- `docs/` — пользовательские документы для индексации.
- `.chatkodi/` — runtime-кэш, индексы, базы, логи, настройки.
- `models_cache/` — legacy/cache моделей, если пользователь уже скачивал их сюда.

## Правило индексации

Индексатор должен читать пользовательский корпус, но не должен читать служебные каталоги:

- `.chatkodi`
- `manuals`
- `tools`
- `scripts`
- `core`
- `gui`
- `plugins`
- `models_cache`
- `.venv`
- `logs`
- `__pycache__`
- `.git`

Это защищает от ситуации, когда ChatKodi начинает отвечать по собственной документации или индексировать support bundle.

## Ядро поиска

Базовая цепочка:

1. Пользователь задаёт вопрос.
2. Query understanding определяет тип вопроса: факт, отчёт, статистика, поиск документов, сравнение.
3. Evidence budget выбирает ширину поиска.
4. Hybrid search поднимает документы и чанки.
5. Structured answer пытается собрать доказательный ответ.
6. LLM используется только там, где она действительно нужна.
7. UI показывает ответ, источники, кнопку уточнения по данным и панель объяснения.

## Новые настройки 1.8

`query_mode` — мягкая подсказка маршрутизации:

- `auto`
- `exact_fact`
- `activity_report`
- `statistics`
- `document_search`

`search_strictness` — ширина поиска:

- `strict`
- `balanced`
- `broad`

Строгий режим уменьшает шум. Широкий режим помогает на лекциях, рецептах, инструкциях и нечётких формулировках.
