# ChatKodi 1.7.3 RC2

## Что усилено

- Более широкий разбор статистических вопросов: `где чаще`, `чем чаще`, `с какой периодичностью`, `в какие дни чаще`.
- Диапазонные запросы теперь получают range-aware structured pipeline вместо попытки ответить по одному лучшему фрагменту.
- Для статистических и диапазонных вопросов structured-answer в RAG теперь приоритетнее свободной генерации LLM.
- EventStore жёстче фильтрует внепериодные события для range-режима.
- В structured output добавлена компактная статистика: даты, направления/места, способы, цели, периодичность.
- Memory guard переводит comparison/range-summary в structured-first режим заметно раньше.

## На что тестировать в первую очередь

- `Где чаще ... с <дата> по <дата>`
- `С какой периодичностью ...`
- `Что происходило ... с <дата> по <дата>`
- `Сравни начало и конец периода ...`
- фактологические вопросы на одну дату, чтобы убедиться, что direct answer не деградировал
