# ChatKodi 1.7.11-rc1 — evidence/source coverage fix

## Что исправлено

- Для target/statistics/range-ответов разделены понятия:
  - прямой ответ,
  - статистика,
  - ключевые доказательства-примеры,
  - все документы-основания расчёта.
- `Использованные документы` больше не строятся только по top-4 evidence-примерам.
  Теперь для статистических ответов берутся все источники из расчётного набора records.
- Для вопросов вида `Какие цели поражены ... за период` evidence-примеры выбираются разнообразно:
  по источникам, датам и целям, чтобы не терялись документы середины/конца периода.
- В статистику добавлены `all_sources` и `source_coverage`, чтобы support/trace мог показать фактическое покрытие расчёта.
- Заголовок блока для статистических ответов изменён на `Документы-основания расчёта`, чтобы было понятно: это не только примеры, а весь набор источников, участвовавший в расчёте.

## Зачем

В 1.7.10 прямой ответ уже учитывал даты 10–15 июня, но блок `Использованные документы` показывал только документы из первых evidence-примеров. Поэтому документы вроде `12.docx` и `15.docx` могли быть учтены в статистике, но не отображаться внизу ответа.
