# CPU/GPU testing guide for ChatKodi 1.7.7

## Принцип

Одна сборка — два режима:

- CPU low memory: поиск + structured answers + статистика без автозагрузки LLM.
- GPU: широкий retrieval, LLM можно использовать как presentation layer.

## Что считается успехом на CPU/i3/8GB

- программа стартует без вылета;
- поиск не падает после долгой индексации;
- RAG на факт/место/способ отвечает structured-first;
- диапазоны и статистика не пытаются отправить весь корпус в LLM;
- если LLM не загружена, RAG не должен падать и не должен зависать на загрузке модели.

## Что считается успехом на GPU

- embeddings и LLM загружаются нормально;
- RAG может использовать LLM, если MemoryGuard разрешил;
- structured evidence всё равно остаётся проверкой ответа.

## Рекомендация

Для первичного тестирования заказчику и разработчику держать:

```json
"query_planner": {
  "enabled": true,
  "use_llm_router": false
}
```

LLM-router — экспериментальный слой. Он полезен, но не должен быть причиной краша.
