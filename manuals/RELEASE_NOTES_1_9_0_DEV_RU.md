# ChatKodi 1.9.0-rc1

## Что добавлено

- Обычное поле чата распознаёт явные запросы на создание тренировочного плана, новых упражнений и юридического документа.
- Фактические вопросы продолжают обрабатываться строгой цепочкой ChatKodi 1.8.
- Внешний корпус каталогизируется без перемещения файлов и без сохранения извлечённого текста в каталоге.
- Для тренировочных материалов отдельно показываются положения документов и дополнения модели.
- Юридический DOCX создаётся как копия безопасного образца. Исходник не изменяется, а сохранение блокируется при старых или незаполненных реквизитах.

## Конфиденциальность

Каталог содержит только пути, имена, контрольные суммы и технические признаки. Текст документов и персональные реквизиты не записываются в каталог, диагностические сообщения или тестовые данные.

## Ограничения dev-сборки

- Точное сохранение оформления поддерживается только для DOCX.
- Результат является проектом для проверки преподавателем или ответственным специалистом.
- Для генерации нужна установленная локальная LLM.
