# ChatKodi 1.6.0 Release Notes

## Что вошло в релиз

- безопасное разбиение проекта на более мелкие модули
- универсальный entity-aware поиск для сущностей вида «слово + номер»
- telemetry и benchmark-инструменты
- healthcheck и diagnostics
- resilience/autoprofile слой с safe-mode и мягкой деградацией
- релизные скрипты запуска и support bundle

## Что важно знать

- без embedding-модели приложение не стартует
- без LLM приложение стартует, но генерация будет ограничена или отключена
- на слабом железе программа может сама выбрать более безопасный runtime-профиль

## Основные файлы для пользователя

- `INSTALL.md` — подробная установка
- `QUICKSTART_RU.md` — самый быстрый старт
- `00_install_windows.bat` — создание `.venv` и установка зависимостей
- `01_download_models.bat` — подготовка моделей
- `02_healthcheck.bat` — проверка окружения
- `03_start_chatkodi.bat` — запуск приложения
- `04_create_support_bundle.bat` — сбор диагностического архива

## Ограничения

- для полного эффекта генерации лучше использовать дискретную NVIDIA GPU
- на слабых CPU-машинах рекомендуется retrieval-first сценарий
