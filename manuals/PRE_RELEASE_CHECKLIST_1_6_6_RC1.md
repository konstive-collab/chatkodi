# Предрелизный чек-лист — ChatKodi 1.6.6-rc1

## 1. Старт и окружение

- [ ] создаётся и активируется `.venv`
- [ ] `pip install -r requirements.txt` проходит без критических ошибок
- [ ] `python main.py` запускает GUI
- [ ] `python healthcheck.py` отрабатывает

## 2. Модели

- [ ] embeddings находятся и загружаются из `models_cache/embeddings/...`
- [ ] локальная LLM находится в `.chatkodi/models_cache/llms/...`
- [ ] при отсутствии `accelerate` нет падения загрузки LLM
- [ ] в логах нет попытки использовать Qwen-папку как embedding-модель

## 3. Документы и индекс

- [ ] документы из `docs/` загружаются без потери корпуса
- [ ] индексация не теряет старый индекс при неудачном rebuild
- [ ] повреждённые `.docx` логируются как ошибки чтения, а не ломают весь процесс
- [ ] режим поиска работает при отсутствии FAISS через numpy fallback

## 4. Функциональные сценарии

- [ ] `SEARCH`: находит нужный anchor-first / answer_rescue фрагмент
- [ ] `EXTRACT`: отдаёт релевантные фрагменты по запросу
- [ ] `RAG + chunks`: отвечает по найденному факту
- [ ] `RAG + full documents`: отвечает по найденному факту
- [ ] `CHAT`: не ломается после переключения из RAG/EXTRACT
