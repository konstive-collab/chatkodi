# ChatKodi 1.6.2 — RAG context fix

## Что исправлено

- Исправлен разрыв между режимом поиска и RAG:
  - поиск умел находить правильный фрагмент внутри уже найденного документа,
  - а RAG часто отправлял в LLM слишком узкий или не тот контекст.
- Для RAG-контекста добавана отдельная логика добора документов и фрагментов:
  - выбираются лучшие документы так же аккуратно, как в режиме поиска,
  - для каждого выбранного документа подтягиваются все его чанки и pinpoint-окна,
  - затем выбираются наиболее ответные чанки, а не только глобальный top retrieval.
- В full-documents режиме RAG теперь может передавать в LLM весь релевантный документ целиком в рамках бюджета контекста, а не только контекст, собранный из случайно выживших retrieval-чанков.
- Синхронный RAG и streaming RAG теперь используют один и тот же путь сборки контекста.

## На что это влияет

Особенно важно для запросов вида:
- объект + дата,
- факт находится в конце документа,
- режим поиска правильный документ находит, но RAG отвечал "В документах нет информации".
