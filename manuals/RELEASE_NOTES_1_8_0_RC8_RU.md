# ChatKodi 1.8.0-rc8

Эта сборка закрывает важное правило: слабое устройство не должно получать тяжёлую LLM автоматически, но пользователь должен иметь возможность включить LLM осознанно.

## Главное

- В лаунчере появилась галочка **«Разрешить LLM даже на слабом ПК — медленно, но запускать»**.
- Ручной выбор конкретной модели теперь тоже считается осознанным разрешением: ChatKodi не будет молча игнорировать тяжёлую модель только потому, что ПК слабый.
- Memory Guard больше не блокирует LLM, если пользователь явно включил её. При этом лимиты контекста остаются экономными, чтобы снизить риск зависаний и нехватки памяти.
- Профиль запуска при форсированной LLM остаётся lazy: главное окно открывается быстрее, а модель грузится только когда нужна генерация или кнопка «Спросить по данным».

## Как пользоваться

Обычный путь остаётся прежним: **Авто**. Он выбирает безопасный режим под устройство.

Если на слабом ноутбуке всё равно нужна локальная LLM:

1. Откройте лаунчер.
2. Перейдите во вкладку **Модели**.
3. Оставьте **Авто** или выберите конкретную модель.
4. Включите **«Разрешить LLM даже на слабом ПК»**.
5. Запустите ChatKodi.

Важно: тяжёлая модель на CPU может грузиться несколько минут. Это не ошибка, если пользователь сам включил такой режим.
