# Поддержка форматов документов в ChatKodi 1.7.18

## Задача

ChatKodi не должен быть привязан только к `.txt`, `.docx` и `.pdf`. Пользователь может принести выгрузку из браузера, старый Word-файл, таблицу Excel, презентацию или обычный лог. Индексатор обязан попробовать извлечь из такого файла чистый текст и только потом строить чанки, поиск, факты и источники.

## Основные поддерживаемые группы

### Текст и код

Поддерживаются обычные текстовые форматы: `.txt`, `.md`, `.markdown`, `.log`, `.csv`, `.tsv`, `.json`, `.jsonl`, `.yaml`, `.yml`, `.xml`, `.ini`, `.cfg`, `.conf`, `.sql`, `.py`, `.js`, `.ts`, `.java`, `.cs`, `.cpp`, `.c`, `.h`, `.go`, `.rs`, `.php`, `.rb`, `.sh`, `.ps1` и похожие.

Такие файлы читаются через набор кодировок: UTF-8, UTF-8 BOM, Windows-1251, KOI8-R, ISO-8859-5 и fallback-декодирование с заменой битых символов.

### Web

Поддерживаются `.html`, `.htm`, `.xhtml` и `.epub`.

HTML очищается от `script`, `style`, `noscript`, затем переводится в обычный текст с сохранением абзацев и заголовков. Если установлен `beautifulsoup4`, используется он. Если нет — работает встроенный fallback на `HTMLParser`.

### Office-документы

Поддерживаются:

- `.docx` через `python-docx`;
- `.doc` через внешние утилиты `antiword`, `catdoc` или `textutil`, если они есть в системе;
- `.doc` fallback-режимом через вытягивание длинных текстовых строк из бинарного файла;
- `.rtf` через `striprtf`, с fallback-очисткой RTF-команд;
- `.odt`, `.ods`, `.odp` через `odfpy`, с fallback-чтением `content.xml` из zip-контейнера;
- `.xlsx`, `.xlsm`, `.xltx`, `.xltm` через `openpyxl`;
- `.xls` через `xlrd`, с fallback-режимом;
- `.pptx` через `python-pptx`;
- `.ppt` best-effort fallback-режимом.

### PDF

PDF читается через `PyPDF2`. Важно: это текстовое извлечение, а не OCR. Если PDF состоит из сканов, текст может не извлечься. OCR лучше добавлять отдельным необязательным модулем позже, потому что он тяжёлый и может резко замедлить слабые машины.

## Принцип отказоустойчивости

Новый reader не должен ломать индексатор. Если конкретная библиотека не установлена или файл повреждён, ChatKodi записывает предупреждение в лог и пропускает файл, а не падает полностью.

Для старых `.doc`, `.ppt` и некоторых битых файлов поддержка считается best-effort. Это честнее, чем обещать идеальное чтение бинарных форматов без установленного офисного конвертера.

## Метаданные формата

У каждого документа теперь есть `metadata.format_family`:

- `text`;
- `document`;
- `spreadsheet`;
- `presentation`;
- `web`;
- `pdf`.

Эти данные нужны для будущих профилей обработки: таблицы можно анализировать как строки/ячейки, презентации — как слайды, HTML — как web-страницы, документы — как абзацы и таблицы.
