# ChatKodi 1.7.0-alpha

## Что нового

- Добавлен **structured answer layer**: для вопросов про факт, место, способ, количество и частоту ответ строится алгоритмически, а не только через LLM.
- Добавлен **query understanding**: типизация вопроса, базовая нормализация объекта, идентификаторов и дат.
- Добавлено **извлечение evidence records** из найденных чанков и базовая агрегирующая статистика.
- Добавлен **memory guard**: при больших корпусах и слабом железе RAG автоматически уходит в chunk-first / structured-first режим.
- Улучшено сохранение **embedding cache**: для небольших корпусов кэш теперь принудительно сохраняется на диск.
- Расширен **support bundle**: теперь в архив попадают runtime metadata, diagnostics/telemetry/recovery логи и runtime root.
- Добавлены утилиты `tools/bootstrap.py` и `tools/doctor.py`.

## Что важно понимать

Это именно **alpha-контур 1.7**, а не финальный stable-релиз. В нём уже заложена новая архитектурная ось:

> факты и статистика сначала, LLM — в конце.

## Ключевой эффект

Если поиск уже нашёл сильный фрагмент, система чаще отвечает через evidence-first слой, а не отправляет весь смысл на откуп генерации.
