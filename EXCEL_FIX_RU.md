# Фото / Excel → нормативный PDF → баллы и сумма

## Запуск обновления

Распакуйте архив в отдельную папку, сохранив старую рабочую копию и пользовательские данные. Запустите START_LAUNCHER.bat и нажмите «Подготовить автоматически»: добавлена зависимость pdfplumber==0.11.7 для извлечения таблиц PDF. Ранее установленную среду также нужно обновить этой кнопкой. Модели и пользовательские документы в архив не включены.

Приложите фото или Excel-ведомость, затем PDF с нормативами; можно разными сообщениями в одном чате. Запрос: «Проставь баллы в ведомости по документу „НФП2023.pdf“ и посчитай сумму». Для однозначного указания используйте точное имя файла или конструкцию «по документу «НФП2023»». PDF может быть в библиотеке: программа ищет его по запросу и номерам упражнений и читает исходный файл, а не только фрагмент поисковой выдачи.

## Реализовано

- Документы с нормативами из предыдущих сообщений учитываются вместе с ведомостью. Явно указанный документ имеет приоритет; отсутствие указанного документа не подменяется другими нормами.
- PDF читается постранично с сохранением геометрии таблиц и физических номеров страниц. Страницы после 30-й не отбрасываются. Норматив на 42-й странице проверен тестом.
- Таблицы на одной странице связываются со своими заголовками в пространственном порядке. Поддерживаются несколько пар «Количество раз / Баллы» рядом.
- Для изображений страниц, включая смешанный текстово-сканированный PDF, используется настроенная модель зрения. Изображения обрабатываются по странице, а не накапливаются все в памяти. Без модели зрения непрочитанные сканы явно перечисляются.
- Оригинальные PDF из библиотеки читаются полностью и кешируются в рамках текущего агента; изменение файла или доступности зрения меняет ключ кеша.
- Поддержаны многострочные заголовки ведомости и повторяющиеся блоки «№ упражнения / Результат / Балл». Строка печатных номеров столбцов не считается человеком.
- Баллы вычисляются программой по точному совпадению с нормативом. Например, упражнение 1, результат 14 → 27 баллов. Интерполяция, округление и приближённая формула не используются.
- Различающиеся таблицы одного упражнения из разных документов считаются неоднозначными. Автоматический выбор по полу, возрасту, категории и весу не реализован: нужен конкретный норматив и его правила выбора.
- После распознавания таблицы без вероятностей токенов выполняется независимое повторное чтение увеличенного изображения. Для таблиц упражнений дополнительная проверка действует и при высокой уверенности первого чтения. Расхождения чисел, ФИО или структуры остаются помеченными, а не заменяются незаметно.
- Неуверенные цифры нормативов со сканов исключаются из таблицы поиска. Неуверенное ФИО, номер упражнения или результат ведомости блокируют зависимые баллы и сумму строки. Совпадение двух чтений не является гарантией отсутствия ошибок.
- Новый Excel содержит формулы точного поиска, сумму, проверки и лист нормативов со ссылкой на файл и страницу. Исходный файл не перезаписывается. Исходное оформление и объединённые ячейки в новом файле не воспроизводятся.
- Пустые необязательные группы не мешают сумме; частично заполненные группы, отсутствующие нормативы и результаты вне таблицы блокируют сумму. Пустая ведомость не получает нулевые результаты.

## Конфигурация пользователя

Для Ryzen 5 7500F, 32 ГБ DDR5 и RTX 4060 начальная рекомендация — уже поддерживаемая проектом Qwen3.5-4B-Q4_K_M.gguf с соответствующим mmproj той же модели. Проектор должен лежать рядом с GGUF; без него текстовая модель не читает фото. Оставьте устройство и профиль в режиме «Авто». Наличие памяти для модели, изображения, контекста и эмбеддингов проверяется при запуске; скорость и качество на RTX 4060 в этой Linux-среде не измерялись.

Новая тяжёлая OCR-модель или сервер не добавлялись. Качество дополнительного OCR-движка следует сравнивать на реальных пользовательских фото; увеличение числа моделей само по себе не подтверждает точность. Длинный полностью сканированный PDF потребует распознавания страниц и может обрабатываться долго; прогресс показывается по страницам.

## Что ещё нужно проверить на исходных материалах

Сам большой PDF и исходные Excel/фото пользователя пока не получены: были представлены скриншоты структуры и двух таблиц нормативов. Тесты используют созданные документы с аналогичной структурой. Качество реального OCR и работоспособность Windows GUI/локальной модели в этой среде не проверялись.

Оценка физической подготовленности и квалификационный уровень не пересчитываются: в представленных скриншотах нет правил перевода суммы в эти значения. Нужен полный нормативный PDF, содержащий правила итоговой оценки, выбор таблиц по категориям, возможные минимумы по упражнениям и правила для пропусков/несданных упражнений. Эти правила не угадываются; существующие значения итоговой оценки сохраняются без пересчёта.

## Проверки

116 тестов выбранных наборов прошли. Проверены реальные PDF с кириллицей и таблицами на поздних страницах, смешанные PDF, выбор явно указанного документа, исходный PDF вместо короткого поискового фрагмента, ссылки на страницы, числовые расчёты, неуверенные ячейки и формирование Excel. Ответы модели в тестах OCR контролируемые; это проверка программной логики, а не измерение качества настоящей модели на фото.

Команда в подготовленной среде:
PYTHONPATH=/workspace/chatkodi-deps:/workspace/chatkodi-pdf-deps python -m pytest tests/test_fitness_points.py tests/test_grading.py tests/test_grading_attachments.py tests/test_pdf_fitness_workflow.py tests/test_agent_actions.py tests/test_conversation.py tests/test_composer.py tests/test_generation_router.py tests/test_reasoned_answer.py tests/test_vision_doubts.py tests/test_vision_orientation.py -q

Для обычной среды разработки установите requirements-dev.txt; reportlab добавлен только для создания тестовых PDF. Новый рабочий пакет pdfplumber добавлен в requirements-app.txt и pyproject.toml.

Из предыдущего расширенного запуска: tests/test_agent.py::test_command_checks требует powershell.exe и не проходит в этой Linux-среде. Модуль проверки PowerShell не изменён.
