# ChatKodi 1.6 — сводная сборка

В этой сборке собраны последние рабочие правки без новых декоративных изменений.

Что включено:
- lazy-загрузка LLM по запросу;
- поиск legacy/new кэшей моделей;
- защита от путаницы `embeddings` и `llms`;
- исправление маршрутизации режимов `CHAT / RAG / EXTRACT`;
- исправление передачи режима `фрагменты / целые документы` в RAG и streaming;
- последние правки GUI по ширине сообщений и поведению shell-интерфейса.

На что смотреть в первую очередь:
- `healthcheck.py`
- запуск `CHAT`, `RAG`, `EXTRACT`
- соблюдается ли режим `Фрагменты / Целые документы`
- новые логи вокруг lazy LLM и RAG context
