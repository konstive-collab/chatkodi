# ChatKodi 2.0.0

Локальная оффлайн-система для поиска и ответов по документам с RAG, структурными ответами, источниками и лаунчером.

## Запуск на Windows

Самый простой путь:

```bat
START_LAUNCHER.bat
```

В лаунчере нажмите:

1. **Подготовить и запустить**

Либо **Только подготовить**, затем **Запустить ChatKodi**.

Документация программы лежит в `manuals/` и открывается прямо внутри лаунчера. Пользовательские документы кладите в `docs/`.

## Важное

- Оставляйте профиль и модель в режиме **Авто**, если не нужна ручная настройка.
- Для кнопки **Спросить по данным** нужна локальная LLM.
- Если LLM не загружается, откройте `manuals/LLM_TROUBLESHOOTING_RU.md` или вкладку **Мануалы** в лаунчере.
