# Структура проекта

Этот файл помогает быстро понять, где в проекте находится нужная логика и какой файл отвечает за конкретную часть системы.

## Корень проекта

### `main.py`

Главная точка входа.

Отвечает за:

- запуск `QApplication`
- настройку Qt-среды на Windows
- запуск главного окна `ChatKodiApp`

Меняйте этот файл, если хотите:

- изменить стартовую последовательность
- добавить раннюю инициализацию
- поменять системные переменные окружения до старта GUI

### `download_models.py`

Совместимая CLI-точка входа. Основная реализация находится в
`tools/model_manager/downloader.py`.

Отвечает за:

- скачивание моделей
- авто-выбор LLM
- проверку локальных моделей
- очистку и восстановление повреждённых моделей

Меняйте этот файл, если хотите:

- поменять каталог `models_cache`
- изменить логику выбора LLM
- добавить новые CLI-флаги
- влиять на то, какие модели считаются приоритетными

### `chatkodi_config.json`

Основной конфиг проекта.

Используйте его, если хотите:

- настраивать retrieval
- менять лимиты контекста
- управлять rerank
- корректировать параметры выдачи

## Папка `gui/`

### `gui/main_window/`

Главное окно `ChatKodiApp`, разделённое на рабочие модули:

- `window.py` — сборка класса окна;
- `ui.py` — виджеты, меню и навигация;
- `bootstrap.py` — безопасный запуск тяжёлых компонентов;
- `settings.py` — пользовательские настройки;
- `documents.py` — импорт, drag-and-drop и переиндексация;
- `messages.py` — сообщения, streaming, история и экспорт.

Меняйте соответствующий модуль этой папки, если хотите:

- поменять дефолтную папку документов
- изменить режим запуска
- поменять логику старта
- настроить поведение без LLM
- поменять экран загрузки и часть визуальных цветов

### `gui/styles.py`

Таблицы стилей Qt.

Меняйте этот файл, если хотите:

- поменять тему
- изменить цвета, рамки, размеры и отступы
- адаптировать внешний вид под свой бренд

## Папка `core/`

### `core/config.py`

Загрузка базового конфига и merge пользовательского JSON поверх внутренних дефолтов.

Меняйте этот файл, если хотите:

- добавить новые разделы в конфиг
- поменять внутренние значения по умолчанию
- использовать другой путь к конфигу

### `core/documents/processor.py`

Загрузка и разбиение документов.

Отвечает за:

- обход папки документов
- чтение `txt`, `md`, `csv`, `pdf`, `docx`
- очистку текста
- разбиение на чанки

Меняйте этот файл, если хотите:

- поменять размер чанков
- изменить overlap
- добавить новые форматы файлов
- поменять лимит размера файла

### `core/search_engine/hybrid_search.py`

Главная поисковая логика `HybridSearch`.

Отвечает за:

- BM25 + semantic retrieval
- сбор кандидатов
- rerank
- работу с датами, идентификаторами и object-like terms
- подготовку результатов для чат-слоя

Меняйте этот файл, если хотите:

- изменить веса BM25/semantic
- доработать правила ранжирования
- скорректировать обработку дат, сущностей и идентификаторов

### `core/chat/manager.py`

Логика режимов `RAG`, `CHAT`, `EXTRACT`.

Отвечает за:

- обработку пользовательского вопроса
- выбор режима ответа
- правила выдачи результатов в `Extract`
- сбор финального текста ответа

Меняйте этот файл, если хотите:

- изменить формат ответа
- поменять лимиты фрагментов
- изменить fallback-поведение без LLM

### `core/models.py`

Загрузка embedding-модели.

Меняйте этот файл, если хотите:

- поменять каталог поиска embedding-модели
- изменить стратегию поиска по подпапкам

### `core/llm/runtime.py`

Загрузка и запуск локальной LLM.

Меняйте этот файл, если хотите:

- поменять каталог LLM
- изменить профили генерации
- подстроить поведение под CPU/GPU
- изменить prompt templates
- внедрить собственную поддержку квантования

### `core/embedding_cache.py`

Локальный кэш эмбеддингов.

Меняйте этот файл, если хотите:

- изменить формат хранения кэша
- поменять правила сохранения

### `core/faiss_manager.py`

Опциональная работа с FAISS-индексом.

Меняйте этот файл, если хотите:

- изменить поведение при наличии `faiss-cpu`
- поменять сохранение и загрузку индекса

### `core/gpu_accelerator.py`

Обёртка над CUDA- и FAISS-возможностями.

Меняйте этот файл, если хотите:

- менять эвристику выбора CPU/GPU
- перенастраивать batch size

### `core/logging_utils.py`

Единая настройка логирования.

Меняйте этот файл, если хотите:

- изменить формат логов
- отключить файловый лог
- поменять путь к логам

## Папка `docs/`

Демонстрационный корпус документов.

Используйте её:

- для первого запуска
- для ручной проверки поиска
- как пример ожидаемой структуры входных данных

## Как искать точку изменения быстрее

Если нужно поменять:

- поведение интерфейса — `gui/main_window/`, `gui/styles.py`
- цвета, рамки, кнопки, фон — в первую очередь `gui/styles.py`
- экран загрузки и спиннер — `gui/components/loading.py`
- поиск и релевантность — `core/search_engine/hybrid_search.py`
- разбиение документов — `core/documents/processor.py`
- ответы и режимы — `core/chat/manager.py`
- модели и оффлайн-режим — `tools/model_manager/downloader.py`, `core/models.py`, `core/llm/runtime.py`
- конфиги — `chatkodi_config.json`, `core/config.py`
